# Superstore-Excel-Dashboard
“Interactive Excel Dashboard using Superstore dataset”

## Features
- KPIs: Total Sales, Total Profit, Quantity, Profit Margin
- Interactive PivotCharts: Sales by Region, Profit by Category, Monthly Sales Trend, Top 5 Products
- Slicers and Timeline for filtering by Region, Category, Segment, and Date

## How to Use
1. Open `Dashboard.xlsx` in Excel.
2. Refresh PivotTables to load data.
3. Use slicers to explore metrics.
